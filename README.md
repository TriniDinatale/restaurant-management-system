# Restaurant Management System

Sistema web de gestión desarrollado para la operación de un restaurante real.

## Objetivo

Centralizar la gestión de pedidos, comandas, turnos, ventas y caja mediante una aplicación web accesible desde dispositivos móviles.

## MVP

- Gestión de usuarios y roles.
- Turnos por sector.
- Gestión de mesas.
- Gestión de productos y categorías.
- Pedidos de salón.
- Pedidos de delivery desde barra.
- Comandas separadas por Pizza, Platos y Barra.
- Asignación de comandas a empleados.
- Coordinación de comandas compartidas.
- Notificaciones en tiempo real.
- Notificaciones Web Push.
- Avisos al mozo cuando una comanda está lista.
- Ventas por mozo y turno.
- Detalle de mesas cobradas.
- Ventas de delivery.
- Caja.
- Movimientos y pagos a proveedores.
- Reportes administrativos.
